# College Management / Student Portal

A simple BCA-level frontend project built with:

- React
- Vite
- Tailwind CSS
- Bootstrap
- React Router
- Lucide React
- Axios installed for future API practice

## Pages

- Home
- About
- Courses
- Students
- Placements
- Gallery
- Career
- Student Portal

## Features

- React Router and Routes
- Navbar and Footer
- Search courses
- Search students
- Search placements
- Search careers
- Search gallery
- Responsive Bootstrap cards
- Tailwind CSS styling
- Student portal dashboard

## Run the project

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Note

The project uses sample data. You can later connect your own API or MongoDB backend.
